# whv-payslip-tracker

オーストラリアのワーキングホリデー中に、**ペイスリップ（給与明細）を1回入力するだけで、ビザ延長の日数（セカンド88日・サード179日）とタックスリターン用の金額をまとめて見られる**Webアプリです。

**公開ページ**：https://ktani-dev.github.io/whv-payslip-tracker/

- 入力したデータは**ブラウザの中（IndexedDB）にだけ保存**し、どこにも送りません。サーバーはありません
- 日数の数え方を3つから選べます（38時間ルール／35時間ルール／公式の割合）。選び直すとその場で計算し直します
- 会計年度（7月〜6月）ごとの総支給と源泉徴収税の合計を出します
- 別の端末へはJSONの書き出し・読み込みで移せます
- 画面は英語です（日本人以外の利用者もいたため）。スマホとPCの両方で使えます

## 背景

ビザ延長の日数とタックスリターンは、どちらも**同じペイスリップから同じ情報（期間・時間・金額）を求められます**。それなのに当時、この2つを一緒に扱えるアプリが無く、周りのワーホリ仲間はみんな手で計算していました。

そこで自分のワーホリ中に、Googleスプレッドシート＋Google Apps Scriptで記録用のシートを作り、約10人（日本人以外も含む）に使ってもらいました。利用者の要望を受けて、次の機能を足しています。

- 週38時間（35時間）のルールで日数を数える
- 総支給（Gross）と手取り（Net）の両方を入れる
- 引かれた税を目安で見る

このリポジトリは、それを**サーバーに送らないWebアプリとして一から作り直したもの**です。

## 日数の数え方

移民局の公式ページ（[Specified work for Working Holiday visa (subclass 417)](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/work-holiday-417/specified-work)）には、「1日＝何時間」の決まりがありません。「その業界・仕事で普通とされる1日の時間」を1日とし、パートタイムは割合で数える、と書いてあるだけです。

一方、バックパッカーの間では「週38時間（または35時間）働けば7日」という数え方が広く使われていて、実際にそれで申請が通っていました（週30時間・35時間では、通った人も通らなかった人もいます）。

どちらが正しいとは言い切れないので、3つから選べるようにしています。

| 選択肢 | 週の時間が基準以上 | 基準未満 |
|---|---|---|
| 38-hour rule（一番確実） | 7日 | 時間÷8 |
| 35-hour rule | 7日 | 時間÷8 |
| Proportional（公式の書き方に合わせる） | 7日 | 7×（時間÷38） |

- ペイスリップが2週間ごとの場合は、期間の週の数に合わせて基準を掛けます（2週間なら76時間）
- 出来高払いで時間が書いていないペイスリップは、働いた日数で数えます（週5日以上で7日）
- **どれも目安です。申請の前に、必ず移民局とATOの公式情報で確認してください**

## 設計で考えたこと

### 1. ルールをコードから出す

制度は変わりやすいです（2026-09には、セカンド・サードを抽選にするという発表もありました）。そのため、88・179・38・35・8といった数字はすべて[src/rules/config.ts](src/rules/config.ts)にまとめ、計算のコード（[src/rules/count.ts](src/rules/count.ts)）には書いていません。

計算は画面（React）から切り離した純粋な関数にして、Vitestでテストしています。38時間ちょうど、2週間で76時間と75時間、会計年度の境目（6/30と7/1）、うるう年などの境目を確認しています。

### 2. 「送らない」を仕組みで守る

ペイスリップには名前・住所・給与などの個人情報が入っています。「サーバーに送りません」と書くだけでなく、公開版のHTMLには**CSP（Content-Security-Policy）で自分のサイト以外との通信を禁止する設定**を入れています（[vite.config.ts](vite.config.ts)）。仮にコードに外へ送る処理が紛れ込んでも、ブラウザが止めます。

### 3. スプレッドシート版から直したこと

| スプレッドシート版 | 今回 |
|---|---|
| 条件（38時間・8時間など）がスクリプトとシートの数式に直書き | 設定ファイル1か所 |
| 入力欄のセル番地に依存 | 入力フォームと型（TypeScript）で項目を定義 |
| エラーがログに出るだけで、利用者に見えない | 入力の確認ウィンドウでその場で知らせる |
| 1セルずつ書き込んで遅い | ブラウザの中で完結 |

## 使い方

1. **Add**の「Enter manually」でペイスリップを入れます。確認用のウィンドウで、何日として数えるかと、その根拠が出ます
2. **Home**で、数えた日数・残り日数と、年度ごとの合計を見ます。上のプルダウンで数え方を選べます
3. **Payslips**で一覧を見ます。1件をクリックすると編集できます

試すときは、Addの「Load demo data」で架空のペイスリップを入れられます。
